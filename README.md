# NellyData portfolio

The source for the NellyData studio site, featuring selected game and data projects, background, and credentials. The site is a static HTML and CSS page hosted with GitHub Pages.

Edit `index.html` to update game announcements, project statuses, experience, or credentials, and `css/style.css` for the design. Add dated entries to the devlog as updates are ready; distinguish experiments from games being prepared for release and link to supporting material where available.
