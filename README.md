# NellyData portfolio

The source for the NellyData studio site, featuring selected game and data experiments, studio background, and development updates. The site is a static HTML and CSS page hosted with GitHub Pages. Keep public copy studio-focused; do not publish personal résumés or private personal contact details.

Edit `index.html` to update game announcements, project statuses, studio practice, or devlog, and `css/style.css` for the design. Add dated entries to the devlog as updates are ready; distinguish experiments from games being prepared for release and link to supporting material where available.
