# NellyData

This is the source for my GitHub Pages home.

I’m a solo game developer experimenting with research-driven workflows for building games, tools, and large fictional worlds with Unreal Engine, C++, automation, and AI-assisted development.

Current focus:

- **Secrets & Superbia** — active Unreal Engine project. Vesper Ward is the first neighborhood-sized pre-alpha slice and the proving ground for the broader Superbia game.
- **Celestium — Pale Pilgrim** — prototype/sandbox work that helped shape the current Unreal and agent workflow.
- **Micare — Cathedral of Lies** — completed C++17 course RPG and an earlier exercise in keeping gameplay, tests, Git history, and documentation aligned.

The basic rule behind the current workflow is:

> research first → implement the smallest useful version → test it in context → record what actually passed → expand from evidence

This site is intentionally a lowkey dev home rather than a formal portfolio.
