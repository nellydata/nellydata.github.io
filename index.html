Projects

This project represents my work throughout COS Project & Portfolio 1 and demonstrates my growth in C++, project structure, version control, debugging, and software development.

C++17 Console RPG

Micare - Cathedral of Lies

Micare is a console-based RPG built in C++17. The player explores the first floor of a mysterious cathedral, investigates rooms, encounters enemies, earns equipment, learns Shimmer abilities, defeats bosses, and unlocks new areas.

Key Features

  • Five-room progression with investigations, enemies, bosses, and room unlocking.
  • Turn-based combat with Shimmer abilities, status effects, equipment, consumables, and Artifact set bonuses.
  • Inventory management with categories, sorting, filtering, pagination, equipment comparisons, and input validation.
  • Automated regression, console, and endurance testing used to verify gameplay systems and progression.

What I Learned

This project helped me improve at organizing a larger C++ codebase, separating responsibilities between classes, working with pointers and references, debugging connected systems, and using Git and GitHub as part of a real development workflow. I also learned the importance of refactoring and testing as a project becomes more complex.
