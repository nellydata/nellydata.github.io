Current Course Project

Micare - Cathedral of Lies

Micare is the C++17 console RPG I developed during COS Project & Portfolio 1. The project grew from a basic multi-class prototype into a complete Floor I gameplay loop with exploration, combat, progression, equipment, abilities, bosses, testing, and final documentation.

C++17 Console RPG

Project Overview

The player explores a cathedral room by room, investigates the environment, encounters enemies, earns XP and equipment, manages Shimmer abilities and Artifacts, defeats progression bosses, and unlocks deeper areas. The project was designed as a complete console RPG loop while also giving me practice managing a larger C++ codebase.

Major Features

  • Five-room Floor I progression with investigations, bosses, and repeatable encounters.
  • Turn-based combat with Shimmer abilities, status effects, consumables, equipment, and Artifact set bonuses.
  • Inventory categories, sorting, filtering, pagination, equipment comparisons, and input validation.
  • Multiple classes and managers separated across header and source files.
  • Regression, console, and endurance testing used to validate gameplay and progression.

Tools & Technologies

C++17, Visual Studio, Git, GitHub, object-oriented programming, vectors, pointers/references, debugging, and version control.

Development Challenge

One of the largest challenges was keeping older parts of the project synchronized as the interface and gameplay systems changed. Some automated tests still expected older inventory, player-panel, and Shimmer menu formats. I updated the validation tools to work with the current game rather than adding special-case behavior to the application, then reran the final build and validation checks.

What I Learned

Micare improved my understanding of organizing a larger program, separating class responsibilities, working with references and pointers, debugging connected systems, refactoring existing code, and using GitHub issues, milestones, branches, commits, and pull requests as part of development.
